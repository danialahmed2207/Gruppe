# Kanban for IT Operations

> Applying Kanban principles to IT support and operations workflows.

---

## What is Kanban?

Kanban is a visual workflow management method that focuses on limiting work in progress (WIP) and optimizing flow. Unlike Scrum, it does not use fixed sprints — work is pulled continuously.

### Core Principles

1. **Visualize the workflow** — Make all work visible on a board
2. **Limit WIP** — Restrict how many items can be in progress at once
3. **Manage flow** — Monitor how work moves through stages
4. **Make process policies explicit** — Define rules for moving items
5. **Implement feedback loops** — Regular reviews and metrics
6. **Improve collaboratively** — Evolve the process incrementally

## Typical IT Operations Board

| Backlog | To Do | In Progress | Review | Done |
|---------|-------|-------------|--------|------|
| Ticket 5 | Ticket 3 | Ticket 1 | Ticket 2 | Ticket 4 |
| Ticket 6 | | | | |
| Ticket 7 | | | | |

**WIP Limits**: In Progress = 2, Review = 1

## IT Support Workflow Stages

| Stage | Description |
|-------|-------------|
| **New / Backlog** | Unassigned tickets awaiting triage |
| **Triage** | Categorize and prioritize |
| **In Progress** | Agent actively working on resolution |
| **Waiting** | Blocked or awaiting user response |
| **Resolved** | Fix applied, pending user confirmation |
| **Closed** | Confirmed resolved |

## Metrics to Track

| Metric | Purpose |
|--------|---------|
| Cycle Time | How long from start to finish |
| Lead Time | How long from request to delivery |
| Throughput | Number of tickets completed per period |
| WIP | Current items in progress |

## Comparison: Scrum vs. Kanban for IT Ops

| Aspect | Scrum | Kanban |
|--------|-------|--------|
| Cadence | Fixed sprints | Continuous flow |
| Roles | PO, Scrum Master, Team | No prescribed roles |
| Change mid-cycle | Discouraged | Allowed anytime |
| Best for | Planned projects | Reactive support work |
| Metrics | Velocity, burndown | Cycle time, throughput |

Many IT operations teams use a **hybrid Scrumban** approach.
